# 旺财简历生成器（wangcai-resume-maker）

帮用户把真实经历做成一份可导入「旺财简历」编辑器的简历 JSON，并交付一键编辑链接。

## 工作流

1. **收集素材**：向用户询问/读取目标岗位、教育经历、工作与项目经历。材料不足时先列清单问，不要编造。技术岗追问 GitHub/作品链接；问清每段经历的三要素（Owner？0→1 还是 1→100？Scope 多大？）。
2. **组装 JSON**：严格按 [references/wangcai-resume-schema.md](references/wangcai-resume-schema.md) 的结构生成。模块顺序默认：求职意向 → 基本信息/教育 → 工作 → 项目 → 技能；有对应素材才加额外模块（honors/certs/portfolio…）。
3. **写作风格（ASu 金标准）**：改写内容前先读 [../references/asu-writing-standard.md](../references/asu-writing-standard.md)，要点——
   - **四段式条目**：「背景与目标 → 我的职责 → 技术实现 → 产出与保障」，行首标签词全文统一；
   - **成果行 XYZ**：达成 [X]·以 [Y] 度量·通过 [Z]；没有确切数据用 `[~X%]` 标注为估算并提醒用户核实；
   - **三要素齐全**：Owner / 0→1 还是 1→100 / Scope（多少人/多少流量/多少营收）；
   - **边界诚实**：只写本人实际完成的部分；保留仓库、PR、Issue 或作品链接；
   - **技术栈分层**：技能标签按语言→框架→数据库→工具链分层，熟练度与项目互相印证，每级 ≤8 词；
   - **版本与方案具体**：写清版本号与技术选型理由；
   - 保留真实学校、公司、部门和指标；学校写官方名称；每行 ≤80 字符。
4. **自检**（必须全过再交付，对照金标准第八节清单）：
   - `JSON.parse` 通过；`schemaVersion===2`；`meta.id` 已生成；
   - 四段式齐全、XYZ 齐全（或缺 Y 已标注）、无「负责/参与」开头（边界声明除外）；
   - 无编造内容；图片（若有）已压缩为 dataURL；单行长度 ≤80 字符。
5. **交付**：运行 [scripts/to-deeplink.mjs](scripts/to-deeplink.mjs) 生成深链，把下方链接给用户：

     ```
     在旺财简历中编辑：https://<站点域名>/builder.html#r=r1.<payload>
     ```

     站点域名用 `WANGCAI_SITE` 环境变量或第二个命令行参数指定。

## 交付文案模板

> 已按你的经历生成简历（不编造内容，估算处已标注 [需核实]）。
> 点击在旺财简历中编辑：<链接>
> 打开后会弹出确认框，导入不会覆盖你已有的简历。

## 红线

- 不编造学校/公司/职位/指标；核不实的写 `[需核实]`。
- 不改用户已提供的事实性内容。
- 深链含简历全文（URL `#` 后不经过服务器，但链接会留在聊天记录/浏览器历史），提醒用户不要发到公开频道。

# 旺财简历生成器（wangcai-resume-maker）

帮用户把真实经历做成一份可导入「旺财简历」编辑器的简历 JSON，并交付一键编辑链接。

## 工作流

1. **收集素材**：向用户询问/读取目标岗位、教育经历、工作与项目经历。材料不足时先列清单问，不要编造。
2. **组装 JSON**：严格按 [references/wangcai-resume-schema.md](references/wangcai-resume-schema.md) 的结构生成。模块顺序默认：求职意向 → 基本信息/教育 → 工作 → 项目 → 技能；有对应素材才加额外模块（honors/certs/portfolio…）。
3. **写作风格（旺财简历写作原则）**：
   - 保留真实学校、公司、部门和指标；学校写官方名称。
   - 项目写清：模块级 Owner、0→1 还是 1→100、技术链、Scope（多少人/多少流量/多少营收）。
   - 每条经历用 STAR 压缩成 2-4 行，每行强动词开头、含量化结果；没有确切数据时用 `[~X%]` 标注为估算并提醒用户核实。
   - 技能标签具体到工具与技术点（「熟练办公软件」→「Excel（透视表/VLOOKUP）」）。
4. **自检**（必须全过再交付）：
   - `JSON.parse` 通过；`schemaVersion===2`；`meta.id` 已生成；
   - 无编造内容；图片（若有）已压缩为 dataURL；
   - 单行长度 ≤80 字符。
5. **交付**（二选一，默认 a）：
   - a) 运行 [scripts/to-deeplink.mjs](scripts/to-deeplink.mjs) 生成深链，把下方链接给用户：

     ```
     在旺财简历中编辑：https://<站点域名>/builder.html#r=r1.<payload>
     ```

     站点域名用 `WANGCAI_SITE` 环境变量或第二个命令行参数指定。
   - b) 链接超长（编码后 >60KB，脚本会提示）时，把 JSON 保存为 `wc-data.json` 放到站点根目录，让用户在编辑器「数据」页点「从此文件导入」。

## 交付文案模板

> 已按你的经历生成简历（不编造内容，估算处已标注 [需核实]）。
> 点击在旺财简历中编辑：<链接>
> 打开后会弹出确认框，导入不会覆盖你已有的简历。

## 红线

- 不编造学校/公司/职位/指标；核不实的写 `[需核实]`。
- 不改用户已提供的事实性内容。
- 深链含简历全文（URL `#` 后不经过服务器，但链接会留在聊天记录/浏览器历史），提醒用户不要发到公开频道。

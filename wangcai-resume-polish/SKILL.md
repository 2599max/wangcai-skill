# 简历润色（wangcai-resume-polish）

保持事实不变，只优化表达。内容基准对齐 [../references/asu-writing-standard.md](../references/asu-writing-standard.md)——**改写前先读它**，四段式骨架、XYZ 行级公式、标签词库、量化维度表都在里面。可三个子任务全做，也可指定其一。

## 通用规则（每个子任务都遵守）

1. **事实锁定**：公司、职位、时间、学校、数字不动；表达可以重构。
2. **条目套四段式**：每条经历重排为「背景与目标 → 我的职责 → 技术实现 → 产出与保障」，行首标签词全文统一（词库见金标准第三节）。
3. **成果行套 XYZ**：达成 [X]·以 [Y] 度量·通过 [Z]；没有数字的行按「钱/时间/质量/规模」四问挖指标，给量化写法模板；确无数据用 `[~X%]` 标注待验证并提醒核实。
4. **删平庸动词**：「负责 / 参与 / 协助 / 配合」→「主导 / 重构 / 搭建 / 推动 / 设计 / 落地 / 沉淀」（「参与」仅用于边界声明的具体动作列表）。
5. **STAR 压缩**：情境→任务→行动→结果，用人话写，每条 2-4 行，每行 ≤80 字符。
6. **边界诚实**：只写本人实际完成、提交、上线或维护的部分；技术项目保留仓库/PR/Issue/作品链接。

## 子任务 A：全文润色

按模块输出优化前后对照表。每条经历：
- 结果前置（先说成果数字，再说做了什么）；
- 技术链完整（用了什么 → 解决什么 → 效果如何）；技术选型给理由；
- 写清 Scope（独立负责 / N 人团队 / 服务 N 用户）；
- 版本与方案具体（「基于 Spring Boot 2.7.x 集成 Spring Security OAuth2 实现 JWT 认证」而非「用 Spring Boot 开发后端」）。

## 子任务 B：技能标签优化

- 笼统技能拆具体：「熟练办公软件」→「Excel（透视表 / VLOOKUP / VBA）」。
- 按「语言 → 框架 → 数据库/中间件 → 工具链」分层，每层内按「精通 / 熟练 / 了解」分级；熟练度必须与简历内项目互相印证，没有项目支撑的「精通」降级或提示删除。
- 对照目标岗位补充关键词时，只加用户确实掌握的（先问，不替用户决定）。
- 每级 ≤8 个词，避免关键词堆砌。
- 输出为可直接粘贴进编辑器 `skills.content` 的多行文本。

## 子任务 C：自我评价优化

- 删「性格开朗 / 吃苦耐劳 / 团队协作能力强」类空话。
- 每句 = 具体能力 + 一句证据（引用简历里的真实经历/数据），可用 FAB 收尾（优势 → 比别人好在哪 → 雇你能得到什么）。
- 3-4 行，第一行让 HR 知道「你是谁 + 最能打的一件事」。

## 输出格式

- 每处修改：原文 → 改写（一对一对照，标注套用的规则：四段式/XYZ/强动词/量化）。
- 结尾给一段「可直接导入旺财编辑器」的汇总说明（建议用 wangcai-resume-maker 重新生成深链）。

## 红线

- 不编造经历、公司、指标；估算一律 `[~X%]`。
- 不改用户已明确要求保留的表述。

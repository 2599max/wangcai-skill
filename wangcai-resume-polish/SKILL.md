# 简历润色（wangcai-resume-polish）

保持事实不变，只优化表达。合并了「全文润色 / 技能标签优化 / 自我评价优化」三件事，按需全做或指定做其一。

## 通用规则（每个子任务都遵守）

1. 事实锁定：公司、职位、时间、学校、数字不动；表达可以重构。
2. 删除平庸动词：「负责 / 参与 / 协助 / 配合」→「主导 / 重构 / 搭建 / 推动 / 设计 / 落地」。
3. 量化补齐：没有数字的成果行，给出量化写法模板；确无数据时用 `[~X%]` 标注待验证估算，并提醒用户核实。
4. STAR 压缩：情境→任务→行动→结果，用人话写，每条 2-4 行。
5. 每行 ≤80 字符，强动词开头。

## 子任务 A：全文润色

按模块输出优化前后对照表。每条经历：
- 结果前置（先说成果数字，再说做了什么）；
- 技术链完整（用了什么 → 解决什么 → 效果如何）；
- 写清 Scope（独立负责 / N 人团队 / 服务 N 用户）。

## 子任务 B：技能标签优化

- 笼统技能拆具体：「熟练办公软件」→「Excel（透视表 / VLOOKUP / VBA）」。
- 按「精通 / 熟练 / 了解」三级分组。
- 对照目标岗位补充关键词时，只加用户确实掌握的（先问，不替用户决定）。
- 输出为可直接粘贴进编辑器 `skills.content` 的多行文本。

## 子任务 C：自我评价优化

- 删「性格开朗 / 吃苦耐劳 / 团队协作能力强」类空话。
- 每句 = 具体能力 + 一句证据（引用简历里的真实经历/数据）。
- 3-4 行，第一行让 HR 知道「你是谁 + 最能打的一件事」。

## 输出格式

- 每处修改：原文 → 改写（一对一对照，方便用户逐条采纳）。
- 结尾给一段「可直接导入旺财编辑器」的汇总说明（建议用 wangcai-resume-maker 重新生成深链）。

# 简历体检（wangcai-resume-audit）

对一份简历做全面体检，输出可执行的修改清单。规则与「旺财简历」编辑器内置的体检引擎（弱动词表、联系方式校验、行长检查）对齐，并叠加证据式真实性审计。

## 输入

- 编辑器导出的简历 JSON / 简历文本 / 用户粘贴的简历内容。
- 若用户提供了晋升材料、项目文档等佐证，一并读取用于核验。

## 体检维度（输出评分表：维度 | 得分/10 | 主要问题）

### 1. 完整性
- 基本信息：姓名、手机（11 位）、邮箱（格式正确）、城市是否齐全。
- 教育：学校（官方名称）、专业、学历、起止时间。
- 工作/项目：每段有公司/项目名、职位、起止时间、≥2 行内容。
- 技能标签是否为空、是否有求职意向。

### 2. 表达（对应编辑器弱动词/量化规则）
- **弱动词开头**：逐行扫「负责 / 参与 / 协助 / 配合 / 完成」——替换建议：主导 / 重构 / 搭建 / 推动 / 设计 / 落地。
- **量化缺失**：没有数字、百分比、规模（QPS/用户量/营收）的条目列出，标 `建议补充量化`。
- **行长度**：单行 >80 字符提示拆行（编辑器里会触发体检警告）。
- 每条经历 2-4 行、强动词开头、STAR 压缩。

### 3. 结构 / ATS
- 模块顺序是否合理（教育+工作在前、荣誉证书在后）。
- 时间线是否连续（ gaps > 6 个月提示）。
- 是否存在大段散文（HR 10 秒扫不到重点）。

### 4. 真实性核验（证据式）
把履历拆成**原子主张**逐条核验，每条标注：`✓ 有佐证` / `? 需核实` / `✗ 与材料冲突`：
- 学校/学位查官方名称与学制。
- 在职时间 vs 项目周期是否自洽；头衔 vs 职责范围是否匹配（宣称 Owner 但描述为参与者要标出）。
- 指标可信度：比例是否异常（如「性能提升 300%」要求给出测法）。
- 无法核实的指标一律建议标注 `[需核实]` 或降级表述。

## 输出格式

1. 四维评分表。
2. **Top 5 问题**（按优先级）：问题 → 为什么影响求职 → 修改前 → 修改后。
3. 真实性核验清单（原子主张表）。
4. 一句话总评 + 下一步行动。

## 红线

- 只标记问题与给建议，不直接改写事实；改写用 wangcai-resume-polish。
- 核验结论必须区分「证据不足」与「确认造假」，不得指控。

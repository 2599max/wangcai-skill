# 面试预测（wangcai-interview-prep）

基于简历内容预测面试问题并准备回答要点。回答素材只来自简历事实，不替用户编故事。

## 工作流

1. **通读简历**，按模块列出「面试官一定会问」的点：最近一段经历、最大的项目、时间线空窗、职级跳跃、高频技术词。
2. **生成 6-8 个问题**，覆盖四类：
   - 深挖类：项目细节、技术选型原因、你具体负责的边界（旺财原则：Owner / 0→1 / Scope 必须答得清）；
   - 挑刺类：指标来源、失败与复盘、为什么离职；
   - 场景类：给你一个新需求/线上事故怎么处理；
   - 匹配类：结合目标岗位（若有 JD）问「你的经验如何迁移」。
3. **每个问题输出**：
   - 问题本身 + 可能的 2 层追问；
   - 考察意图（面试官在筛什么）；
   - 回答要点（STAR 结构的提纲，30 秒能讲完）；
   - 需要提前准备的数据/材料（如「当时的监控截图」「需求文档要点」）。
4. **风险预警**：简历里 `[需核实]` 标注的估算、时间线 gap，面试前必须想好说法——列出清单。

## 输出格式

按「必问题（3）+ 高概率题（3-5）+ 风险预警清单」组织；每个问题独立成块，方便用户逐条演练。

## 红线

- 回答要点是提纲不是台词，鼓励用户用自己的话讲。
- 不建议隐瞒或美化事实；空窗与失败给「诚实框架」模板。
